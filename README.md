# Workout Tracker

A local-first Android workout tracker I built for a structured 4-day training program to help with my military PT requirements. All data stays on your device. No accounts, no cloud, no ads.

Requires Android 15+

## Features

### Workout Logging
- Pre-loaded 4-day workout plan covering upper body, lower body, and conditioning splits
- Log weight, sets, and reps for strength exercises
- Log duration and difficulty for timed exercises like planks, farmer carries, and conditioning circuits
- Log distance and duration for cardio including running, treadmill walking, and intervals
- Same-day override so logging the same exercise twice in one day replaces the earlier entry

### Walking
- Standalone walking tracker that lives outside the workout days
- Dual-unit distance entry that converts between miles and kilometers automatically
- Duration tracking with pace calculation

### Overview Dashboard
- At-a-glance stats for key lifts like bench press, squat, deadlift, pull-ups, and push-ups
- Best times and distances for timed exercises and cardio
- Walking stats with best distance and pace
- Time period filters to see where you stand
- Percentage change with trend indicators

### Progress Charts
- Per-exercise line charts showing improvement over time
- Switchable metrics including weight, total volume, reps, duration, distance, and pace
- Overall change summary with percentage delta
- Single data point shows up as a starting marker

### Data Backup
- Export all data to a JSON file through the system file picker
- Import from a backup file to restore everything
- No special permissions required
